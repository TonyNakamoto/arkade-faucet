# Security

## Reporting a vulnerability

If you believe you have found a security issue in this project, please **do not** open a public GitHub issue for it.

Instead, report it responsibly:

- Use [GitHub **Private vulnerability reporting**](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) for this repository if it is enabled, **or**
- Contact the repository owner through a private channel (e.g. email or social profile listed on their GitHub account).

Include enough detail to reproduce or understand the issue (version/commit, affected component, impact).

## Scope & expectations

This is a **faucet** application: it can move **real funds** when configured with live keys. Operators are responsible for their own deployment, keys, monitoring, and incident response.

There is **no guarantee** of timely response or a fix. See the [README](README.md) disclaimer.
